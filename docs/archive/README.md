# Archived design specifications

Files in this directory are historical design records, not authoritative implementation instructions.

`MILESTONE_0.6.1_SPEC_ARCHIVE.md` records the original Domain Population Reforge plan. It contains superseded implementation details, including the abandoned v3-to-v4 save migration and the original single-PR scope.

For current work, use `ROADMAP.md`, `ARCHITECTURE.md`, `GAME_DESIGN.md`, `BALANCING.md`, `SAVE_FORMAT.md`, and the active milestone task as the source of truth.
